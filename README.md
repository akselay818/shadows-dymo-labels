# Shadows & Sweethearts DYMO Label Maker

For Chrome on a Chromebook with the DYMO LabelWriter 550 and a genuine 30336 roll (1 × 2⅛ in).

## Deploy on GitHub Pages

Replace the repository files with the contents of this ZIP, keeping the directory structure, including `.github/workflows/deploy.yml`. Commit the files to `main` to trigger the existing GitHub Pages workflow. After the workflow succeeds, open https://akselay818.github.io/shadows-dymo-labels/ in Chrome and reload the page.

## Connect and print

Open the hosted HTTPS page in a regular Chrome tab. Connect the printer over USB, click **Connect DYMO 550**, and select the printer in Chrome’s picker. Use **Compact** or **Standard** for overall text size, then adjust the product name separately if needed. The barcode and SKU are centered beneath the price. Print one label and check its barcode before printing a batch.

Square CSV data stays in the browser. The app also supports single-label PNG export and batch printing.
